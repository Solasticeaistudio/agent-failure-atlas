# 90-day roadmap

## Month 1 — Trace conformance and failure taxonomy

- Publish the STS-native MVP, synthetic smoke set, CLI, and Space.
- Add adapter fixtures for Codex, Claude Code, Pi, Hermes, and smolagents OpenTelemetry exports.
- Define a versioned failure taxonomy with community review.
- Add trace-size limits, streaming parsing, and stronger local privacy scanning.

## Month 2 — Open-model agent benchmark

- Build 20 deterministic scenarios across scope, injection, approval, recovery, and efficiency.
- Run the same tasks through several open models with a fixed harness and tools.
- Separate model, harness, tool, and policy variables in the result schema.
- Add human labeling guidance and inter-rater agreement reporting.

## Month 3 — Public dataset, Space, and research note

- Publish redacted traces and labels as a Hugging Face Dataset.
- Expand the Space with trace comparison, evidence navigation, and model/harness slicing.
- Release a short report on failures hidden by final-answer-only evaluation.
- Submit at least one upstream documentation or integration pull request to the Hugging Face ecosystem.
